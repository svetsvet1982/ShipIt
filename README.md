# SHIP IT — 스타트업 비즈니스 영어 회화 드라마

미국 오스틴의 미용 주사제(HA 필러) 스타트업 **Veyra Aesthetics**가 창업에서 글로벌 진출까지 가는 8부 120화(화당 120턴) 학습용 회화 대본.

## 구성
- `ShipIt_기획서.md` / `.docx` / `.pdf` — 전체 기획서(인물, 제품 특장점, 8부 120화 회차표, 복선 맵, 학습 설계)
- `대본/N부/NN화_Title.md` / `.docx` / `.pdf` — 화별 대본(영어 대사 → 학습 부록 → 한국어 번역 순, 대사 번호 없음)
- `대본/N부/N부_..._통합본.docx` / `.pdf` — 부별 통합본(화마다 새 페이지)
- `대본/연속성_노트.md` / `.pdf` — 화별 확정 사실·호칭·습관어·미회수 복선 누적 기록
