# SHIP IT — 스타트업 비즈니스 영어 회화 드라마

미국 오스틴의 미용 주사제(HA 필러) 스타트업 **Veyra Aesthetics**가 창업에서 글로벌 진출까지 가는 7부 105화(화당 120턴) 학습용 회화 대본.

## 구성
- `ShipIt_기획서.md` / `.docx` — 전체 기획서(인물, 제품 특장점, 7부 105화 회차표, 복선 맵, 학습 설계)
- `대본/N부/NN화_Title.md` / `.docx` — 화별 대본(영어 대사 + 한국어 번역 + 학습 부록)
- `대본/N부/N부_..._통합본.docx` — 부별 통합 워드본
- `대본/연속성_노트.md` — 화별 확정 사실·호칭·습관어·미회수 복선 누적 기록
