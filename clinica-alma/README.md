# CLÍNICA ALMA — 스페인어 비즈니스 회화 드라마

마드리드의 피부과 의사 마테오가 참베리에 미용의학 클리닉을 열었다가, 한국 오송의 필러를 직접 들여오며 '의사에게만 파는' 유통사 Alma Médica를 세운다. 직판과 지역 서브 딜러 망으로 스페인·포르투갈을, 합작으로 멕시코·콜롬비아를 열고, 로트 유출 위기와 제조사의 직판·인수 제안 사이에서 '영혼'을 지키기까지. 클리닉은 끝까지 남는다. 8부 120화, 대사 100% 스페인어(스페인·멕시코·콜롬비아·아르헨티나 변이), B1 → C1+.
